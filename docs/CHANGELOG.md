# 版本变更

## 0.2.0 — 首次可运行交付

- 完整牌局状态机：14张庄家起手，四方摸舍，吃碰明杠暗杠补杠，自摸/接炮/流局，撤销、浏览器恢复、导入导出和回放。
- 按用户补充加入白板鬼、可选七对/十三幺/鸡胡及可吃配置。
- 概率模型v0.2：白板鬼精确胡牌搜索；已知舍牌继续计数；被鸣取的舍牌只计一次。
- 下一摸自摸概率与固定集合多摸窗口概率分开显示，结构推荐明确为启发式。
- 6组Monte Carlo实验、200局四人流程、特殊牌型与状态机回归测试；公开统计报告及示例牌局。
- 静态构建、Cloudflare Workers Assets部署配置、CI与模型说明。
